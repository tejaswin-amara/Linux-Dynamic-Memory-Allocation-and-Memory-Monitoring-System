# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of our memory allocator and task monitoring system seriously. If you identify a security vulnerability or potential privilege escalation:

1. **Do NOT open a public GitHub issue.**
2. Send an email directly to `tejaswin.amara@gmail.com` with:
   - Reproduction steps or Proof of Concept (PoC)
   - Affected system components (Allocator, VFS parser, or GUI server)
   - Expected vs observed behavior
3. We will acknowledge receipt within 48 hours and work with you on a patch before public disclosure.
